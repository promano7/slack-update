## Checked bytes, races and compatible mechanisms

An earlier pathname checksum does not bind later pathname execution if the name or
an ancestor changes. Verify regular opened object, all canonical ancestry and
reviewed mount context, owner/mode/effective ACL/capabilities and exact approved bytes.

content/dependency stability through use. A retained descriptor can address pathname

mtime or post-run hashes alone do not certify the bytes consumed. Writer exclusion
is a separate313 requirement; concrete owner/access bindings remain316.

O_NOFOLLOW on a leaf does not exclude ancestor symlinks. Component-aware openat2 or
