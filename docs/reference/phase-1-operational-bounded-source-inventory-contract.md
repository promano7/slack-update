## Future reader contract

Walk relative directory descriptors from the approved root with `O_DIRECTORY`
and `O_NOFOLLOW`,then open the final component read-only with `O_NOFOLLOW` and
`O_NONBLOCK`. Reject symlink ancestors and final symlinks,nonregular files,path
escapes/control characters,duplicate roots,invalid UTF-8 and NUL. Check size before
bounded reads,exact observed SHA/length against the approved snapshot,and open-FD
stat identity/metadata before and after. Fail on drift. These rules will be tested
in361;this design validator does not claim an implemented secure filesystem walk.

Retain original LF/CRLF and Unicode bytes without normalization. Byte identity
proves only what the reader observed against this repository snapshot. It does
not prove native immutable lifetime,writer exclusion or checked-to-used identity
of any interpreter,helper,installed executable,archive or hook.

## Lexical evidence and source anchors

Record textual hints in stable source order,line order and declared kind order.
Each anchor binds path,source SHA,one-based physical line,zero-based start byte,
line byte length including its original terminator,full raw-line SHA,and a UTF-8
prefix bounded at a codepoint boundary. All hints have the explicit status
`lexical-candidate-context-and-runtime-relation-unresolved`.

Hints cover definition-like text,source/eval/exec names,command substitutions,
redirection/pipelines,here documents,command names,payload markers,dynamic command
text and trap/process text. They are not a shell parser. Matches inside comments,
strings,here documents,foreign-language blocks or generated payloads remain
uncertain. Function/command-looking text never establishes a call,reachable edge,
callee version,writes or absence of effects. No matches never means no dependencies.

The historical generated artifact is not a second independent worker;its embedded
copy is not decoded in361. Any later decoded-source review needs an explicit new
byte binding. External helpers,slackpkg/pkgtools,installed shell/libraries,package
archives/hooks,namespace/platform/storage primitives and dynamic path resolution
remain missing native inputs for both Slackware15.0 and Slackware-current.

## Future report and controls

A report must retain selected source descriptors,hint records,unresolved relations,
coverage limitations and explicit repository-only boundaries. It cannot assert
native graph completeness,installed versions,conformance,host closure or authority.
Hard errors return no successful prefix report. Future CLI output is report data
to the caller;it does not write a source or invoke an inspected program.

The contract lists eighteen required361 control families,including a dangerous
shell sentinel that stays unexecuted,symlink/FIFO/nonregular and traversal refusal,
byte/line/record budgets,read/hash drift,exact LF/CRLF/non-ASCII anchors,lexical
ambiguity,no-hint unknowns and explicit rejection of false native completeness.
360 tests validate data shapes,receipt/source bindings,bounds and anchor semantics;
they are not filesystem-reader or native conformance tests.
