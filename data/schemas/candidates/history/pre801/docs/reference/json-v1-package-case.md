## Interface and boundaries

`assess_package_case(result_bytes, profile, expectations, observations)` with its
frozen private records. There is no CLI, dispatcher, collector, path hydration,
adapter, fallback, producer integration or public wire-format change. Invalid
private record shapes raise ValueError; valid unknown facts remain pending data.
Unknown/incomplete captures can retain declared size/hash claims, but those claims
cannot establish complete-byte agreement. Conflicting known prefixes remain
mismatches while completeness stays pending. Not-produced never fabricates stdout;
attempted command streams and required original pin data cannot both be declared
not-produced merely to obtain agreement. Known unattempted commands cannot carry
invented complete or incomplete command streams.

The unchanged exact candidate reader checks complete prospective apply shape.
Its only schema inputs are the two existing repository candidate schemas.
Present malformed/wrong-family/v0 results yield a shape mismatch. Absent results
remain absent and package checks pending; independent process/stderr facts stay
separate. Captured-operation status is compared to valid JSON code; serializer
process0 is not treated as an apply process0. Declared capture origin is unverified.

Checks cover literal full result agreement, declared identities/configuration/pin,
complete bytes and integrity declarations, ordered selectors/effects, applicability,
absorbing forward-failure latches, raw-result correspondence and expected outcome.
They retain matched/mismatched/pending tuples simultaneously. `data_disposition`
prefers mismatch over pending over match. A guard-only match means its scoped
condition has no known conflict; it is not successful native admission.

with all applicable selector/source/identity/independent-capture criteria retained.

raise ValueError. Install0 does not inherit install20's stdout rules.

Matching failure data, recovery or publication cannot erase the original failure.
All four authority/acceptance flags always remain false. Full original12 evidence
